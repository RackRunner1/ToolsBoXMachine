What is ToolsBoXApp?

ToolsBoXApp (TBXA) is our new project: the full ToolsBoXMachine experience, packaged as an app installed directly on your Linux PC. Same tools, same speed, same simplicity, but running but running entirely from your own machine.

📦 Same toolbox

Every TBXM tool you already know, available as a desktop app.

⚡ Same behavior

Identical features and interface to the website version.

Why go local?

When you visit the website, your browser has to contact our servers through Cloudflare to load the pages. Like most CDN providers, Cloudflare may keep connection logs, including IP addresses.

With TBXA, that step disappears: everything is local. No page loads over the network, no requests to Cloudflare, nothing to log. You can even turn off your internet connection. The app keeps working exactly the same way.

Compatibility

TBXA currently supports Linux only (Debian/Ubuntu derivatives via .deb, Fedora/RHEL derivatives via .rpm, with Arch Linux support on the way).

Windows and macOS are unfortunately not supported, as explained in discussion #33 on GitHub. Only Linux is supported for now.

Installation

Open a terminal and run the one-line installer. It detects your distribution and installs the matching package automatically:

curl -fsSL https://tbxm.org/install.sh | bash

Prefer to install manually? Download the package for your distribution from our GitHub releases page, then install it with your package manager. Once installed, you are ready to go.

Updates and removal

TBXA is managed from the terminal with the tbxa command:

  • To update to the latest version: tbxa update
  • To remove the app: tbxa uninstall
tbxa update
tbxa uninstall
