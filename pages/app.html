Why go local?

When you visit the website, your browser contacts our server to load each page. We do not log those visits, but the requests still travel over the network. With TBXA, that step disappears: everything runs on your machine, with no requests to our server.

Windows

Supported since Nov 14, 2026

Windows is now supported and tested. Download the installer and run it like any other Windows app.

  1. Download the .exe file from the GitHub releases page.
  2. Run the installer and follow the instructions.
  3. Launch ToolsBoXApp from the Start menu.

Linux

Run the one-line installer. It detects your distribution and installs the matching package.

curl -fsSL https://get.tbxm.org | bash

Prefer to install manually? Packages are available for:

  • Debian / Ubuntu and derivatives (.deb)
  • Fedora / RHEL and derivatives (.rpm)
  • Arch Linux and derivatives (.pkg.tar.zst)
View all releases

Updates and removal

On Windows and Linux, TBXA is managed from the terminal with the tbxa command.

Update

Get the latest version.

tbxa update

Uninstall

Remove the app from your system.

tbxa uninstall
